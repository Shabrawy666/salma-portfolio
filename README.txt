SALMA AHMED — PORTFOLIO WEBSITE
===============================

STEP 1 — ADD THE IMAGES
  Double-click  copy-images.bat  (Windows). It copies image.jpeg, image1.jpeg ... image18.jpeg
  from C:\Users\Lenovo\Downloads\writer into the "assets" folder.
  (Or copy them into "assets" by hand. Keep the same file names.)

STEP 2 — VIEW THE SITE
  Double-click index.html (Chrome / Edge / Firefox).

EDITING
  All text, links and image names are in works.js.
  Works with no link have  url: ""  (they show a status badge and are not clickable).

PUBLISHING + DOMAIN
  Free hosting: Cloudflare Pages (drag & drop the folder) or GitHub Pages.
  Then add your domain in the host and add the DNS records it shows you at your registrar.
  GitHub Pages apex domain: four A records ->
    185.199.108.153  185.199.109.153  185.199.110.153  185.199.111.153
  www: CNAME -> <your-username>.github.io
